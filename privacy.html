Privacy Policy

Effective Date: October 2026

This Privacy Policy describes how the personal backup utility application handles your data when accessing Google Drive via rclone.

1. Data Collection

This application does not collect, store, or transmit any personally identifiable information (PII) to any external or third-party servers. All authorization tokens and credentials remain strictly on the local client device executing the synchronization jobs.

2. Use of Google User Data

The application requests Google Drive API scopes strictly to perform user-initiated file operations (uploading, downloading, and managing backup files). The application does not analyze, monitor, or use file contents for any purpose other than executing file transfers.

3. Data Sharing and Transfer

No user data, file metadata, or authorization credentials are sold, transferred, or shared with third parties.

4. Security

OAuth 2.0 tokens are held locally in your local rclone configuration file and are used solely to establish direct communication between your machine and Google Drive endpoints.
